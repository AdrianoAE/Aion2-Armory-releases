# Aion 2 Armory

Build planner, Daevanion boards, daily/weekly planner and event timers for AION 2 (Windows).

## Install

1. Open the [latest release](https://github.com/AdrianoAE/Aion2-Armory-releases/releases/latest) and download `Aion2_Armory.zip`.
2. Unzip it anywhere (keep `Aion2 Armory.exe` next to its `_internal` folder).
3. Run `Aion2 Armory.exe`.

## Updates

Nothing to do: on every start the app checks this page, and when a newer version exists it downloads it, verifies the checksum, installs it and restarts itself.

Your characters and settings are kept in `%APPDATA%\Aion2 TM\Profiles`, outside the app folder, so they survive updates.
